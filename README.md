# Local LLM Setup and Run Guide

Author: Onkar Mundhe

## Prerequisites

- Windows 10/11
- Node.js

## Setup

Run these commands in PowerShell:

```powershell
cd "C:\Users\onkar.arjunmundhe\Desktop\Local_llm\llama-cpp-custom\tools\server\webui"
npm install
```


## Build (Production)

```powershell
cd "C:\Users\onkar.arjunmundhe\Desktop\Local_llm\llama-cpp-custom\tools\server\webui"
npm run build
```

## App URL

- `http://localhost:5173`

## Stop Application

Press `Ctrl + C` in the terminal.
